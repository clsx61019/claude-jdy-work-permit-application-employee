# 规则清单：9.6. Betétlap（就业 Foglalkoztatás）

- **官方模板：** `templates/official/09_6_Foglalkoztatas_HU.docx`（官方匈牙利语 Word 可填写表单，27 个勾选框、100 个文本域；与官方 PDF `09_6_Foglalkoztatas_HU.pdf` 一致）
- **实现：** `service/forms/form09_6.py`；测试样例 `tests/samples/employment_employer.json`、`employment_client.json`、`employment_extension.json`
- **生成：** 同时输出 Word 和 PDF。
- **适用范围：**
  - **居留许可类型：** Employment（模板 9 的居留目的勾 9.6 时一起生成）
  - **人员分类：** 全部 5 类（Expat / Local Recruited / Board Member / Extended Stay / External）。万华外派目前只在旧 Employment 许可延期时用到；不按人员分类限制许可类型
  - **申请类型：** New 新申请 / Change 变更 / Extension 延期，差别只在「之前在匈牙利工作」一块（Q3）
- 和 9.5、9.10 相同的规则直接沿用已确认的决定，下表注明「同 9.5」「同 9.10」。
- **金额格式：** 福林不要小数（`HUF 1.250.000`）；人民币保留两位小数（本表不用人民币）。
- **官方格子拆成多段：** 例如电话是 #2#3#4 三个连续的空域，只填第一个，其余留空。
- **和 9.5 / 9.10 不同：** 9.6 没有「ügyfél által / foglalkoztató által」和签证领取地那一块，所以递交地点（匈牙利 / 中国）对本表没有影响。
- **旧简道云模板：** `templates/jdy/09_6_jdy_original.docx`，对照结果见文末「和旧模板的差异」。
