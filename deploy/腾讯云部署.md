# 部署到腾讯云（测试）

打印服务做成一个 Docker 镜像（Python + LibreOffice + 模板），部署成腾讯云函数的 **Web 函数**（镜像部署），地域默认 **法兰克福 eu-frankfurt**（数据留在欧盟）。
构建、测试、推送、部署都在 GitHub Actions 里自动完成，密钥只放在 GitHub Secrets 和云函数环境变量里，不进仓库。

## 一次性准备（腾讯云控制台）

1. **子账号和 API 密钥**：访问管理 CAM → 用户 → 新建子用户（编程访问），授权 `QcloudSCFFullAccess`，再加上 `QcloudAccessForScfRole` 的角色传递权限（如果控制台提示）。记下 SecretId / SecretKey。
2. **容器镜像服务 个人版**：容器镜像服务 TCR → 切到「个人版」，地域选 **法兰克福** → 初始化密码 → 新建命名空间（例如 `wanhua-hr`，全局唯一）。
   页面上显示的仓库域名就是 `TCR_REGISTRY`（法兰克福一般是 `deccr.ccs.tencentyun.com`，以控制台为准），登录用户名是主账号 ID（UIN）。
   个人版如果不能开通，就开企业版实例，把 `TCR_IMAGE_TYPE` 设为 `enterprise`，`TCR_REGISTRY_ID` 填实例 ID。
3. **云函数**：首次进入云函数控制台时按提示授权服务角色 `SCF_QcsRole`。函数本身不用手动建，Actions 会建。

## GitHub 设置

仓库 → Settings → Secrets and variables → Actions：

| 类型 | 名称 | 内容 |
|---|---|---|
| Secret | `TENCENTCLOUD_SECRET_ID` / `TENCENTCLOUD_SECRET_KEY` | 第 1 步的子账号密钥 |
| Secret | `TCR_USERNAME` / `TCR_PASSWORD` | 镜像仓库登录名（主账号 ID）和第 2 步设的密码 |
| Secret | `JDY_API_KEY` | 简道云 开放平台 → API 密钥（J12），需要能读写「签证管理」应用 |
| Secret | `GEN_TOKEN` | 自己编一串长随机字符，调用接口时要带上 |
| Variable | `TCR_NAMESPACE` | 第 2 步的命名空间 |
| Variable | `TCR_REGISTRY` | 仓库域名（不填默认 `deccr.ccs.tencentyun.com`） |
| Variable | `TENCENT_REGION` | 不填默认 `eu-frankfurt` |
| Variable | `JDY_APP_ID` | `67501067fec27368c50bdf57`（签证管理） |
| Variable | `JDY_ENTRY_ID` | 测试表「工作许可申请/变更/延期流程_测试」：`6ae1e985c2c60828dfc71ed4` |
| Variable | `FIELD_WORD` / `FIELD_PDF` | 两个附件字段的 `_widget_` ID（J10）。只建一个就只填 `FIELD_WORD` |
| Variable | `FIELD_SELECT` | 可选：多选框「选择要生成的文件」的 `_widget_` ID，选项文字见 `service/config/forms.json` |
| Variable | `FIELD_RESULT` | 可选：多行文本「生成结果」的 `_widget_` ID，写生成了什么、跳过了什么 |

## 部署

仓库 → Actions → 「部署到腾讯云」→ Run workflow。日志最后会打印函数 URL；也可以在云函数控制台「函数 URL」里看到。

## 测试

浏览器打开（把记录 ID 换成测试表里的一条记录）：

```
https://<函数URL>/generate?token=<GEN_TOKEN>&data_id=<记录ID>&format=html
```

- 不带 `forms` 时：读多选框 `FIELD_SELECT`；它也没配或为空时，生成所有适用的文件（9.x 附件只出与居留许可类型对应的那份），不适用的跳过并写明原因。
- `forms=9 居留许可申请表,预协议` 只生成指定的几份。
- `format=zip` 不写回简道云，直接下载压缩包（还没建附件字段时用这个测试）。

预期会跳过的：J13（雇主代表）没填时，预协议、雇主用工情况报告、TAJ 订购单会跳过；J15 没做时，NAV / TAJ 授权书会因为缺被授权人信息跳过。

## 从简道云触发

两种方式，测试时再定：

1. **前端事件 / 自定义按钮**调用 `/generate`，参数带 `token` 和 `data_id`。记录要先保存。生成二十来份约 5–10 秒（冷启动再多十几秒），如果前端事件超时就改用第 2 种。
2. **数据推送**到 `/jdy-webhook`（Secret `JDY_PUSH_SECRET` 填推送的签名密钥）：多选框 `FIELD_SELECT` 有值时生成，写回附件后把多选框清空，所以用户勾选文件 → 提交 → 稍后刷新就能看到附件。

## 费用

按调用计费（内存 × 运行时间），测试期用量很小；镜像个人版免费。具体以腾讯云账单为准。
